# Working rules

- For any change (code, config, docs), create a new branch and commit to it —
  never commit directly to `main`. Commit messages follow
  [Conventional Commits](https://www.conventionalcommits.org/) (`fix:`,
  `feat:`, `docs:`, `test:`, `chore:`, etc.), matching this repo's existing
  history. Name branches `type/short-description` (e.g. `fix/queue-cas-under-load`),
  matching this repo's existing branches (e.g. `feat/queue-notifications`).
